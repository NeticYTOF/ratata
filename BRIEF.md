# Ratata brief (from Aarav, verbatim intent)

Ratata is a CLI tool built fully in Rust, natively, that downloads videos, images and assets from many social media apps like Instagram, YouTube and Twitter/X. It supports as many platforms as possible and downloads them very fast, natively in Rust.

The CLI must look extremely beautiful and animated. It must download as quickly as possible: use many optimization methods (parallel/segmented connections, connection reuse, resumable downloads, smart retries, etc.).

The UI must be very good, themed on flowers and tunnels: tunnels, with flowers in the tunnels. It is a terminal app / terminal UI / terminal CLI. Make it look very, very beautiful, very fast and snappy, built in Rust.

## Standing rules
- Commit every 30 minutes at minimum (commit early and often) and push to the GitHub repo each time.
- Never idle. There is no stopping point. Keep adding big features, polish and speed work until told to stop. Big tasks, not tiny tests.
- Full access is on: never ask for permission, just do it.
- Keep a PROGRESS.md updated with what is done, what is left, what is blocked.
